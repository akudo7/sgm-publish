# Root SKILL.md

This repository stores skills under the `skills/` directory.

## How to find skill instructions

- Each skill has its own `SKILL.md` under `skills/<skill-name>/SKILL.md`.
- If you need a skill, search with `glob_files` for `skills/**/SKILL.md` and then `read_file` the relevant one.
